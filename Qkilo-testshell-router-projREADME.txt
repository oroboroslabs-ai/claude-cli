Project: Transcriptions and Related Scripts

This project folder contains the following directories:

- Raw: For storing unprocessed transcription files.
- Clean: For storing processed transcription files.
- Scripts: For storing any scripts used in the transcription process or for processing files.
- Logs: For storing logs related to the transcription or processing tasks.

Please ensure that only relevant files are placed in each directory and keep the structure clean for better organization.
